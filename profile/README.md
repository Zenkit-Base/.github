# Project Overview

Zenkit is a project management and collaboration platform designed for organizing projects, tasks, documents, schedules, communication, and knowledge in a unified workspace.

The platform supports both agile and traditional project-management workflows and can be adapted to different organizational structures. Projects can be represented through multiple views, including Kanban boards, tables, Gantt charts, calendars, and mind maps.

Zenkit is also available as a suite of connected applications. Its ecosystem includes project management, task management, team communication, forms, and knowledge-management tools that can work together through a shared data platform.

The service is available through the web as well as dedicated applications for Windows, macOS, Linux, iOS, and Android.

---

# Project Management & Organization

Zenkit provides tools for planning and tracking projects from initial ideas through completion. Tasks can be organized into projects and assigned to team members with due dates, reminders, comments, and progress information.

Different project-management methods can be represented within the platform, including Agile, Scrum, Kanban, Waterfall, Lean, and customized workflows. Users can choose views that match the way they prefer to manage information.

Projects can contain tasks, subtasks, checklists, files, comments, and other information required to coordinate work. Custom fields and workflows can also be used to adapt projects to specific requirements.

---

# Tasks, Lists & Collaboration

Zenkit To Do provides dedicated task-management features for personal and team workflows. Users can create tasks, organize them into lists, assign tasks to other people, add due dates and reminders, and create recurring tasks.

Smart Lists such as Today, This Week, Starred, and Assigned to Me provide additional ways to organize daily work.

Tasks can contain comments, tags, files, subtasks, and checklists. The platform also supports sharing lists and folders with colleagues, friends, or family members.

Offline access is available in Zenkit To Do, allowing users to continue working with tasks when an active connection is unavailable. Changes can be synchronized when connectivity returns.

---

# Views, Planning & Custom Workflows

Zenkit allows information to be displayed in different formats depending on the project. Supported views include Kanban, Gantt, table, calendar, dashboard, and mind-map-oriented workflows.

This flexibility allows the same project information to be used for different purposes. A team might use a Kanban board for day-to-day task tracking while using a Gantt view for longer-term scheduling.

Custom projects can also be created for workflows beyond traditional project management, including customer management, content management, resource tracking, issue tracking, and other structured datasets.

---

# Knowledge Management & Zenkit Suite

Zenkit's wider ecosystem includes Hypernotes for knowledge management, documentation, wikis, notes, and interconnected information. Hypernotes supports outlining, bi-directional links, semantic knowledge graphs, annotations, and built-in task management.

The Zenkit Suite allows information and tasks to be connected between different products. For example, tasks created within Hypernotes can also be managed through other Zenkit applications such as Base or To Do.

Zenchat adds team communication and connects conversations with tasks and project information, while Zenforms provides forms and survey functionality.

---

# Integrations, Security & Enterprise Features

Zenkit provides collaboration and administration features designed for organizations. Depending on the plan, these can include two-factor authentication, access controls, user roles, groups, SAML-based single sign-on, SCIM provisioning, and auditing capabilities.

The platform also supports integrations with external services through Zapier, allowing Zenkit workflows to connect with a large number of other applications.

Zenkit states that its infrastructure is GDPR compliant and that data is stored on servers in Germany.

# System Compatibility & Performance

Zenkit is available across desktop, mobile, and browser platforms. The official platform information lists Windows, macOS, Linux, iOS, and Android support.

| Component        | Practical Configuration                                       |
| ---------------- | ------------------------------------------------------------- |
| Operating System | Windows 10/11, macOS, Linux, iOS, Android                     |
| Architecture     | x86/x64 and supported platform architectures                  |
| Processor        | Modern dual-core processor                                    |
| Memory           | 4 GB RAM or more recommended                                  |
| Storage          | Minimal for the application; additional space for cached data |
| Graphics         | Integrated graphics                                           |
| Display          | 1280×720 or higher recommended                                |
| Internet         | Required for online synchronization and collaboration         |
| Browser          | Modern Chrome, Edge, Firefox, Safari or compatible browser    |

The Windows desktop application requires Windows 10 according to Zenkit's current platform information. Linux downloads are provided in `.deb`, `.rpm`, `.tar.gz`, and `.AppImage` formats, while macOS versions are available for Intel and Apple Silicon systems.

Actual resource usage depends on the number of projects, tasks, files, connected integrations, browser tabs, and active applications.
